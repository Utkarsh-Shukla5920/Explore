# Hidden Nepal 🇳🇵

## About the Project

Hidden Nepal is a website I made to share the beauty of Nepal and help people discover interesting places around the country.

Nepal has many beautiful destinations, from mountains and hills to peaceful places and amazing landscapes. I wanted to create a simple website where people can explore some of these places.

## Pages

- **Home:** An introduction to Hidden Nepal.
- **Place:** Explore different places in Nepal.
- **About:** Learn more about this website.
- **Contact:** Get in touch with me through the contact details or message form.

## Built With

- HTML
- CSS
- JavaScript

## Features

- Simple and clean design
- Navigation between different pages
- Background images of beautiful places
- Responsive layout for different screen sizes
- Contact form for sending messages
- Mobile navigation menu

## Purpose

I created this project to practise my HTML, CSS, and JavaScript skills while building something related to my country, Nepal.

I am still learning web development, so I hope to improve the website and add more places and features in the future.
